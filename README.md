# Правовой консультант

**Офлайн-справочник по законам РФ:** 382 источника, 25 812 статей и пунктов с
полным текстом, поиск по тексту, разбор ситуации с указанием норм,
калькуляторы сроков и пошлин, памятки, чек-листы и готовые шаблоны
документов. Без регистрации, без оплаты, работает офлайн.

> 🌐 **Сайт:** https://zTRPGz.github.io/pravovoy-konsultant/
> Хостинг — **GitHub Pages** (домен `vercel.app` больше не используется).

## Возможности

- **Поиск по тексту** — мгновенный поиск по всем статьям (в том числе по
  фрагментам и с учётом морфологии русского языка), живой поиск прямо при
  наборе.
- **Полные тексты статей** — открываются сразу, с хлебными крошками, оглавлением
  кодекса, хронологией редакций и входящими ссылками.
- **Помощник (разбор ситуации)** — отвечает только ссылками на статьи из базы
  (`ID статьи + дата редакции`), показывает, по каким признакам сделан вывод,
  и может отвечать **строго по выбранным источникам** (например, только по
  Уголовному кодексу).
- **Калькуляторы** — сроки давности, процессуальные сроки, пошлины и др.
- **Справочный слой** — аннотации к статьям, термины, разборы типовых ситуаций,
  правила «если — то», памятки, чек-листы следственных действий, шаблоны
  документов и готовые исковые заявления.
- **Версии и статусы норм** — действующие редакции, сравнение редакций,
  реестр утративших силу и приостановленных норм.
- **Связи источников** — граф перекрёстных ссылок между актами.
- **«Дела»** — рабочие папки со своими подборками норм, тегами и заметками.
- **Экспорт в `.docx`** с оформлением по ГОСТ Р 7.0.100-2018 и цитированием по
  ГОСТ 7.0.5-2008.
- **Тёмная и светлая темы** — тема по умолчанию следует системной настройке
  устройства; переключение меняет и рамку окна браузера/статус-бар телефона.
- **Офлайн** — после первого открытия страница и тексты сохраняются в браузере
  (service worker), поиск и разбор работают без интернета. Данные не
  передаются никуда.
- **Адаптивность** — одинаково удобно на ПК и на телефоне (нижняя навигация,
  выезжающее меню, safe-area для «чёлок» и жестовых кнопок).

## Как пользоваться

Всё работает прямо в браузере, ничего устанавливать не нужно.

1. **Откройте сайт** https://zTRPGz.github.io/pravovoy-konsultant/ — первая
   загрузка чуть дольше (подтягиваются данные), дальше открывается мгновенно и
   офлайн.
2. **Найдите норму.** В строке поиска введите слово, номер статьи
   (`ст. 158 УК РФ`) или фразу — результаты появляются по мере набора. Можно
   ограничить поиск одним источником (режим одного источника в меню источников).
3. **Откройте статью.** Нажмите на результат — откроется полный текст с
   хлебными крошками, оглавлением кодекса, датой актуальной редакции и
   входящими ссылками. Кнопки `← / →` переключают статьи, как в книге.
4. **Спросите Помощника.** Перейдите в раздел «Помощник» и опишите ситуацию
   своими словами (например: *«Петров, 17 лет, предложил двум лицам похитить
   товар, остался снаружи, те зашли и украли»*). Помощник вернёт только ссылки
   на статьи (`ч. 2 ст. 158 УК РФ`, `ч. 3 ст. 33 УК РФ`) с пояснением, по
   каким признакам сделан вывод, и кнопкой «Почему такой ответ».
5. **Используйте калькуляторы и шаблоны.** Раздел «Калькуляторы» — сроки и
   пошлины; раздел «Документы» — заполняемые шаблоны (заявление, протокол,
   иск) с экспортом в `.docx`.
6. **Сохраняйте подборки.** Кнопка избранного добавляет статью в «Дела» —
   папки с тегами и заметками; подборку можно выгрузить или импортировать.
7. **Проверяйте актуальность.** Раздел «Свежие изменения» показывает, что
   изменилось в нормах; при наличии сети работает проверка актуальности базы.
8. **Переключайте тему.** Кнопка в шапке меняет тёмную/светлую тему; выбор
   запоминается. Тема по умолчанию — как в системе телефона/ПК.

## Запуск локально

Сборка не нужна: скачайте репозиторий и откройте `index.html` в браузере.

Для проверок и полного набора данных нужен Node.js 18+:

```
npm install
npm run serve        # http://localhost:8080
```

## Команды

| Команда | Что делает |
|----|----|
| `npm run build` | скачивает акты с официального портала и собирает `data/` |
| `npm run build:data` | пересобирает `data/` из уже скачанных выгрузок |
| `npm run audit` | проверяет целостность базы: потери статей и глав |
| `npm run verify` | полная приёмка: целостность, тексты, прогон приложения |
| `npm run dist` | собирает каталог публикации `dist/` |

## Откуда данные

Источники — `ruslaw-public` и API официального портала
`actual.pravo.gov.ru`; судебная практика (постановления Пленума и обзоры
Президиума ВС РФ) — с `sudact.ru`. Ночная сборка в 23:30 МСК обновляет базу
и пересобирает сайт. Полные тексты актов авторским правом не охраняются
(пункт 6 статьи 1259 ГК РФ).

## Структура проекта

```
index.html      разметка и загрузчик данных
app.js          всё приложение — один файл, без сборки
styles.css      оформление (в том числе мобильные слои и тёмная/светлая темы)
sw.js           офлайн-работа (service worker)
data/           база: реестр, индекс, тексты статей, справочный слой
tools/          сборка, проверки, локальный сервер
DEPLOY.md       как публикуется сайт и как обновляется база
```

Граф перекрёстных ссылок считается при сборке и лежит готовым файлом
`data/graph.js` — разделу «Связи источников» не нужно подгружать тексты всех
актов, поэтому он открывается сразу.

## Как публикуется сайт

Сайт публикуется на **GitHub Pages** из ветки `main` (workflow
`.github/workflows/pages.yml` собирает `dist/` и выкладывает его). Ночное
обновление базы — отдельный workflow `.github/workflows/update.yml`:
скачивание актов → сборка данных → проверки (`audit`, `verify-data`,
`smoke-test`) → коммит и пуш.

> Примечание: в репозитории сохранён `vercel.json` — он используется только как
> источник правил кеширования для сборки (`tools/build-dist.js` переносит их в
> `dist/_headers`). Публичный адрес сайта — только GitHub Pages, домен
> `*.vercel.app` неактивен.

## Добавление новых материалов

Данные собираются из `vendor/ruslaw/*.json` (этот каталог вне git) в `data/`
командой `npm run build`. **Не правьте `data/` вручную** — полнотекстовый
поиск разбит на 32 сегмента, и правка нарушит консистентность. Для добавления
статей, ФЗ, ФКЗ, кодексов, постановлений используйте утилиту
`tools/add-article.js` — она пишет только в `vendor/ruslaw`, а сборка сама
перегенерирует индекс и тексты.

**Добавить статью(и) в уже существующий источник** (его `id` берётся из
`data/registry.js`, например `uk`, `koap`, `fz-...`):

```bash
# из JSON-файла (массив или один объект: {number, title, text})
node tools/add-article.js --src uk --file articles.json

# или поштучно
node tools/add-article.js --src uk --number 107 \
  --title "Убийство в состоянии аффекта" \
  --text "Статья 107. ..."
```

**Создать новый источник** (новый ФЗ / ФКЗ / кодекс / постановление):

```bash
node tools/add-article.js --new --id fz-999 --kind law \
  --short "ФЗ «О примере»" --full "Федеральный закон «О примере»" \
  --number 999-ФЗ --branch "Конституционное право" \
  --file articles.json
```

После `--new` утилита создаст файл в `vendor/ruslaw/<id>.json` и напомнит
**зарегистрировать** источник в `data/registry.js` (`RF_CODES`) с тем же `id`,
иначе `add-article.js --src <id>` и сборка его не увидят.

После любой правки `vendor/` обязательно пересобрать и прогнать приёмку:

```bash
npm run build
node tools/audit.js && node tools/verify-data.js
```

## Правовой статус

Тексты актов взяты из официальных источников и авторским правом не
охраняются. Справочный слой — аннотации, памятки, чек-листы, шаблоны,
разборы ситуаций — и код приложения охраняются: цитировать со ссылкой на
источник можно, копировать в свой продукт — нет. Подробно — в файле
[LICENSE](LICENSE).

Приложение не заменяет консультацию юриста: для юридически значимых действий
сверяйтесь с официальной публикацией.
